# Guilherme Jacob · Jacob Costa

**Senior Software Engineer at Leaf Agriculture** · Applied AI · Full-stack engineering · Cloud infrastructure

I build the AI assistants in Leaf’s agriculture dashboard. They help people explore field data and edit charts. I built the Python harness that gives each assistant the tools it needs, rolls back pending edits when a user cancels, and catches stalled or repeated tool calls in regression tests. The dashboard runs on React and TypeScript.

I previously built AI harnesses and integrated language models into Pinterest’s Help Center as a contractor. At Itaú, I built tools that helped banking teams analyze file-transfer data and automate parts of their workflow.
