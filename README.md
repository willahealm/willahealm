# Guilherme Jacob · Jacob Costa

**Senior Software Engineer** · Applied AI · Full-stack engineering · Cloud infrastructure

I’m a full-stack engineer with more than a decade of experience. I like working on a feature from end to end, from the interaction someone sees in React to the service behind it and the pipeline that ships it. These days I spend much of my time connecting language models to tools people use in their daily work.

One example is a dashboard where people can explore agricultural data and edit charts with an AI assistant. I built the Python harness that connects the model to the chart editor. If someone presses Stop midway through an edit, the harness restores their draft. I wrote regression tests for the less obvious cases, like a model calling the same tool over and over.

I’ve also modernized services and integrated LLMs on the HelpCenter team, built tools that help banking teams make sense of file-transfer data, and mentored engineers through code reviews and workshops. Outside of engineering, I’m into games and space.
